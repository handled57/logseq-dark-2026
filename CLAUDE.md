# Development

SDLC: Make a topic branch -> Make code changes -> Pull from main -> auto resolve merge conflicts -> Automated testing -> Merge to main when done -> Tag the new version and push it all to origin.

I want you to automate everything. all the Git things, development, QA, tagging and pushing to origin, finding bugs and fixing them, refactoring, etc.


Bug fixes:
* When fixing a bug, be proactive find all other instances where the root cause could cause an issue and apply the fix.
